# Contributing to SkyCast

Thanks for your interest in improving SkyCast!

## How to contribute

1. Fork the repository.
2. Create a feature branch:
   ```bash
   git checkout -b feature/your-feature
   ```
3. Make your changes and test the website in a browser.
4. Keep the code readable and use descriptive names.
5. Commit your changes:
   ```bash
   git add .
   git commit -m "Add: describe your change"
   ```
6. Push your branch and open a pull request.

## Before submitting

- Check that city search still works.
- Check both Celsius and Fahrenheit modes.
- Test the layout on mobile and desktop widths.
- Handle API errors clearly; do not silently show misleading weather data.
- Do not commit API keys, passwords, or private credentials.
